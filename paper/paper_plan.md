
# 论文背景

量子计算领域的飞速发展，威胁到了以椭圆曲线和离散对数等数学难题为核心的现有密码算法。近年来，许多项目都开始后量子转型，用抗量子密码算法替换软件中不安全的密码算法。

区块链系统可以利用智能合约实现密码算法，但是密码算法这类复杂操作会带来较高的手续费。针对这个问题，以太坊提出了预编译合约的方法，通过预编译合约为复杂计算逻辑设置一个较低的Gas费用。

但是预编译合约的方式牺牲了灵活性，预编译合约的实现与客户端软件绑定，其更新通常依赖客户端源码修改、重新构建和节点软件部署，增加了升级协调成本，并可能导致升级期间的服务中断或节点版本不一致。

无论是利用智能合约还是预编译合约都无法兼顾灵活性与执行效率。为此我们提出了"密码学协处理器"的概念。通过在EVM侧平级设置一个计算模块，作为协处理器负责处理EVM侧有关密码算法的调用，协处理器作为独立的单元可以在EVM处理交易的同时完成密码算法的更新。

本文的贡献包括：
1. 提出密码学协处理器架构，将面向 EVM 的密码算法调用接口与客户端 Native 实现解耦，为密码算法运行时更新提供独立执行与管理单元。
2. 设计链上协调、链下异步执行的密码算法升级机制，使编译与加载过程脱离交易执行关键路径。
3. 我们基于geth实现了密码学协处理器的原型，并在实验环境中，测试了方案升级效率、算法执行效率、升级一致性。

# 研究问题
1. 如何解耦智能合约侧密码算法调用接口与客户端 Native 实现
2. 如何在不中断EVM执行情况下完成密码算法升级
3. 节点异步完成升级后，如何保证确定性执行

# 核心设计 

1. 协处理器架构，协处理器管理面向智能合约的密码算法 Native 实现，并支持其运行时替换。
2. 链上升级管理与链下编译，开发者通过链上合约发送升级Event，客户端监听事件并异步完成动态编译以及载入。
3. 一致性保证，升级完成后在指定的Activation Block切换到新密码算法。确保执行稳定性。

## 实验一 升级延迟与可用性

测量从提交升级交易到各节点完成密码算法编译、加载并进入 Ready 状态的端到端延迟，并分析链上确认与链下升级准备的时间组成。

## 实验二 密码算法执行效率

测试智能合约通过密码学协处理器调用 Native 密码算法时的执行时间与 Gas 开销。

## 实验三 升级过程状态一致性

在节点升级准备时间不一致的条件下，于 Activation Block 前后持续执行密码算法调用，验证各节点是否在相同区块高度选择相同算法版本，并保持交易结果与 State Root 一致。
